# Hodoki

グループの立替と、メンバーごとの負担割合をまとめる共有会計アプリです。

## できること

- グループとメンバーを作成し、URLで共有
- 支払った人、明細、金額、日付を記録
- グループ全体に適用する負担率を設定
- 個別の明細だけ別の負担率に上書き
- 1円単位で負担額を配分し、端数を自動調整
- メンバーごとの立替額と負担額から、精算の送金先・金額を計算
- 複数人から同時に更新された場合、更新競合を検知

グループのURLを知っている人は内容を閲覧・編集できます。ログインは不要です。共有リンクは会計データへのアクセスキーとして扱い、個人情報などを含む記録は作成しないでください。

## 公開ページ

[Hodokiを開く](https://hodoki-expense-sharing.starrybook7.chatgpt.site)

## 使い方

1. グループ名とメンバー名を入力して作成します。
2. 「全体の負担率」でグループ全体の割合を設定します。合計が100%になると保存できます。
3. 立替明細を追加し、支払った人、金額、分け方を入力します。
4. 通常は全体の割合を使い、特定の明細だけ分け方を変える場合は「この明細だけ」を選びます。
5. 精算のまとめに表示された金額を確認し、必要ならコピーして共有します。

割合で割り当てた金額の端数は、各明細の合計が元の金額と一致するよう1円単位で配分します。

## 開発

Node.js 22.13以降とpnpm 11.25.0を使用します。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

データベースはDrizzle ORMとCloudflare D1を使用します。スキーマを変更した場合は `pnpm db:generate` でマイグレーションを生成します。公開環境への反映はSitesのデプロイ時に行います。

## 技術構成

Next.js互換のVinext、React、TypeScript、Cloudflare Workers、D1、Drizzle ORM。
